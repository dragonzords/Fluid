# Fluid

Music player for Android based on [Metro](https://github.com/muntashirakon/Metro) (a fork of
RetroMusicPlayer), with online search and streaming powered by the `innertube` module taken from
Pear Music.

- Local library + Metro UI as before.
- Search now also shows **online songs** (a "Fluid Online" section under your local results).
- Tapping an online song streams it; cover art and lyrics (LRCLIB) are fetched online.
- No account / login. Personal use.

Package: `com.asphyx.fluid`

## Build

Android Studio (JDK 17) → open the project → Sync → Run `app`.
